# Example Inputs

Work does not need to be organized before it goes into the Command Center.

These are the kinds of updates you can give it naturally throughout the day:

```text
I have to finish the prototype before Thursday.

Sent the revised deck.

Waiting on engineering before I can move forward.

We decided not to pursue the second option.

I need to follow up on the accessibility review next week.

This isn't a task, but I want to remember that the team raised concerns about the current workflow.

I have 45 minutes before my next meeting. What should I work on?

What am I forgetting?

Give me a pulse check.
```

The Command Center should interpret these updates using the context it already has, without requiring you to manually label something as a task, blocker, decision, dependency, or completed work.
